# Sign-up and sync — plan

Spec: `docs/superpowers/specs/2026-10-18-signup-design.md`. Branch `signup`, preview
`https://signup.rookahead.pages.dev`.

1. **Schema + setup guide** — `supabase/schema.sql` (table, RLS, `delete_account`), and
   `docs/supabase-setup.md` (project, Google client, Resend SMTP, email templates, redirect URLs).
2. **Merges** (TDD) — `src/lib/syncMerge.ts`: `mergeGames`, `mergeReviews`, `mergePuzzles`,
   `mergeSettings`, `mergeStore(key, …)`.
3. **Sync bus** — `src/lib/syncBus.ts`: synced key list, `markChanged(key)` (dirty + time in sync
   meta, schedules a pass), `onStoresChanged`/`useStoreVersion` for pages. Wire into `saveProgress`,
   `saveGame`, `saveReview`, `useSettings`.
4. **Sync pass** (TDD) — `src/lib/sync.ts`: `syncOnce(remote, userId, storage)` against a `Remote`
   interface; meta handling, conditional writes, retries, first sign-in, `forgetLocal()`.
5. **Auth + Supabase adapter** — `src/lib/account.ts`: lazy client, `useAccount()`, Google / email /
   code / logout / delete, URL callback handling, scheduling of passes, `Remote` over `user_stores`.
6. **UI** — `AuthDialog`, user card states, Settings → Account, header avatar, CSS.
7. **Reloads** — Puzzles, Home and settings re-read their store after a pass changes it.
8. **Privacy page**, env vars (`.env`: `VITE_SUPABASE_URL`, `VITE_SUPABASE_KEY`).
9. Verify: tests, lint, build; manual run against the real project; push preview; user OK; merge.
